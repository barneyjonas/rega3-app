# rega3-app

The PC desktop version of rega3, built with Electron + React + TypeScript.

## What's in this repo

- `electron/` — Electron main process, preload bridge, tray, and local SQLite database layer
- `src/` — React UI (components, hooks, stores, types, utils)
- `package.json` / `tsconfig.json` / config files — project setup and build config

## What's NOT in this repo

- `node_modules/` — installed automatically, not stored in git. Run `npm install` to restore.
- `out/` — compiled build output, generated by the build step. Run `npm run build` to regenerate.

## Getting started

```bash
npm install
npm run dev     # start in development mode
npm run build   # build for production
```
